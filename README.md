# Discord 帖子导出

一个浏览器小插件：把你在 Discord 网页上**看过的帖子**，打包成**一个 zip 文件**，方便丢给 AI 看。

zip 里面有：

- `thread.md`：整个帖子的聊天记录。谁说的、几点说的、回复的是哪一楼、点了什么表情，都写得清清楚楚
- `images/`：帖子里的图片

---

## 它能干嘛？

- 📜 **导出聊天**：每条消息都有编号，比如 `[12]`，`↩#5` 就是“这条在回复第 5 楼”
- 🖼 **导出图片**：重复的图片只放一张。比如你发了好几版角色卡，卡面没变，后面就只写“同第几张图”，不让 AI 白看好几遍
- 😀 **表情和反应**：消息里的表情、底下点的表情（👍×24 这种）都会记下来
- 🕒 **发帖时间**：不用翻到第一楼也能知道帖子是哪天发的
- 💰 **省 AI 额度**：格式很精简，没用的东西都去掉了

## 安全吗？

- ✅ **不碰你的账号密码和登录凭证**
- ✅ **不偷偷访问 Discord 的接口**：它只是“抄”你屏幕上已经显示出来的内容
- ✅ **平时不干活**：没打开开关的时候，它什么都不做，页面上也看不到它

---

## 怎么装？（电脑上的 Edge 或 Chrome，装一次就行）

1. 把这个项目下载下来：点 GitHub 页面上绿色的 **Code** 按钮 → **Download ZIP**，然后解压
2. 浏览器地址栏输入 `edge://extensions` 回车（Chrome 是 `chrome://extensions`）
3. 打开 **「开发人员模式」** 开关
4. 点 **「加载解压缩的扩展」**，选刚才解压出来的那个文件夹（里面要能看到 `manifest.json`）
5. 搞定！刷新一下 Discord 网页

> ⚠️ 装好以后**别删、别挪**这个文件夹，浏览器每次都从这里读插件。
>
> 📱 手机用不了。安卓的 Edge、Via 这类浏览器都装不了这种插件。

## 怎么用？

**第 0 步：打开开关**
点浏览器右上角的插件图标，图标上出现蓝色 **ON** 就是开了，再点一下就关掉。
（找不到图标？点右上角的拼图 🧩，把「Discord 帖子导出」固定出来）

**第 1 步：打开帖子，自己往上/往下翻**
你翻到哪，它就记到哪。右下角按钮会显示「已记录 N 条」。

**第 2 步：点「📥 导出」**
确认一下标题，等它打包完，zip 就会像平时下载东西一样，出现在你的“下载”文件夹里。

**懒得自己翻？**
右下角还有两个小按钮：

| 按钮 | 作用 |
|---|---|
| ⤒ | 自动往上翻到帖子第一楼 |
| ⤓ | 自动往下翻到最新消息 |

翻到头会自己停。想中途停下，再点一下（变成 ⏹ 的那个）就行。打包图片的时候点「导出」按钮，也能中途停下。

```
—— 2026-10-01 ——
[1] 14:02 小明
你好 :pepe: 看这个
🖼 images/001-1.png
反应：👍×3

[2] 14:05 小红 ↩#1
同意 👍

[3] 09:15 小明
又更新了
🖼 （画面同 images/001-1.png，不重复附图）
```

## 怎么给 AI 看？

- **Claude Code 这类能直接读电脑文件的 AI**：告诉它 zip 在哪，让它解压后先读 `thread.md`，要看图再打开 `images` 里对应的图
- **网页版 AI（ChatGPT、Claude 网页版等）**：有“代码执行/沙箱”功能的，可以直接传 zip；没有的话，解压后**只传 `thread.md`**，需要看哪张图再单独把那张图拖进去。文本里写了哪张图在哪一楼，AI 对得上号

## 常见问题

**Q：导出的内容不全？**
A：它只记你翻过的部分。想要全部，就从头翻到尾，或者点 ⤒ 和 ⤓。文件开头会写“从帖子第一条开始”或“只含浏览过的部分”，一看就知道全不全。

**Q：有的图写着“图片没能下载”？**
A：太老的图片链接可能已经失效了，没办法。

**Q：有的地方写着“未知”？**
A：那是指向别的帖子的链接，Discord 网页上本来就显示“未知”，导出的跟你看到的一样。

**Q：刷新页面后记录没了？**
A：对，记录只存在当前页面里。刷新、关掉页面就清空了，不会在电脑上留下任何东西。

**Q：Discord 改版后不好用了？**
A：有可能，因为它是照着 Discord 网页的样子来认消息的。到时候把导出结果发给会写代码的 AI 让它修一下就行。
